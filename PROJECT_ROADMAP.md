# Project Roadmap

This roadmap keeps my portfolio work focused on practical, job-ready development.

## Current Priorities

- Improve responsive frontend layouts and accessibility.
- Build and document Campus Connect as a useful student platform.
- Develop FarmGenie AI with a clear multi-agent architecture.
- Strengthen Python, JavaScript and Java problem-solving skills.
- Keep project repositories organised with clear README files.

## Development Checklist

- [ ] Define the user problem before coding.
- [ ] Create a simple UI flow and responsive layout.
- [ ] Build the smallest working version first.
- [ ] Test the main user journey on desktop and mobile.
- [ ] Document the setup, features and next improvements.

## Definition of Done

A project is ready to showcase when it has a clear purpose, a working demo or walkthrough, readable code, setup instructions and a short list of future improvements.
