# Security Policy

## Supported Versions

This portfolio repository is maintained on the `main` branch. Security fixes, dependency updates, and important configuration changes should be made against the latest version.

## Reporting a Vulnerability

If you find a security issue in this project, please avoid posting sensitive details in a public issue. Instead, contact the repository owner privately through the contact details listed on the GitHub profile.

When reporting an issue, include:

- A clear description of the problem
- Steps to reproduce it
- The affected file, page, or component
- Any screenshots or logs that help explain the issue
- A suggested fix, if you have one

## Responsible Disclosure

Please allow reasonable time for the issue to be reviewed and addressed before sharing technical details publicly. Thank you for helping keep this project safe and professional.
