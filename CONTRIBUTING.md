# Contributing to My Portfolio

Thank you for your interest in improving this portfolio repository.

## How to contribute

1. Fork the repository or create a feature branch.
2. Make focused changes with clear, readable code or documentation.
3. Test the change locally before opening a pull request.
4. Use a descriptive commit message.
5. Explain what changed and why in the pull request description.

## Quality checklist

- Keep the design responsive and accessible.
- Use clear naming and consistent formatting.
- Avoid committing secrets, API keys, or personal credentials.
- Update the relevant documentation when a feature or project changes.

## Suggested commit format

```text
Add: short description of the change
Fix: short description of the issue
Docs: documentation-only update
```
